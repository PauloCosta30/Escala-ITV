# Projeto: Sistema de Relatório de Visita Técnica - Versão Simplificada

## Objetivo
Criar uma página única com formulário completo, upload de fotos e exportação em PDF. Sem banco de dados, sem salvamento.

## Funcionalidades

### Página Única (Index)
- [ ] Criar página única com todos os campos do formulário
- [ ] Seção de dados do projetista
- [ ] Seção de dados do cliente
- [ ] Seção de informações da central
- [ ] Checklist de verificação com checkboxes
- [ ] Tabela de quantitativos editável
- [ ] Avaliação de dificuldade (0-10)
- [ ] Observações e ações

### Upload de Fotos
- [ ] Sistema de upload de fotos
- [ ] Campo de observação/legenda para cada foto
- [ ] Visualização de fotos adicionadas
- [ ] Opção de remover fotos
- [ ] Galeria de fotos no formulário

### Exportação PDF
- [ ] Exportar relatório completo em PDF
- [ ] Incluir todos os dados preenchidos
- [ ] Incluir todas as fotos com observações
- [ ] Formatação profissional do PDF

### Limpeza

- [ ] Remover rotas desnecessárias
